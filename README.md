# Физика 10 класс — курс и викторина

Статический сайт из трёх вкладок: обзор школьного курса физики 10 класса,
интерактивная викторина и страница об авторе. Без сборки, зависимостей
и интернета — достаточно открыть `index.html`.

Оформление — тёмная тема с фиолетовым акцентом (`#8b5cf6`), включая
SVG-иллюстрации вопросов, которые генерируются в той же палитре.
Автор проекта — **@Jimmy**.

**Живой сайт:** <https://benzovoz36.github.io/physics10-quiz/>

Сайт публикуется через GitHub Pages из ветки `main` (корень репозитория):
после пуша страница пересобирается автоматически за минуту.

## Запуск

- Двойной клик по `index.html`, или
- локальный сервер (удобнее для проверки в разных браузерах):

```bash
python -m http.server 8000
```

и открыть <http://localhost:8000>.

## Вкладки

- **О предмете** — что изучает физика в 10 классе: кинематика, динамика
  и законы сохранения, молекулярная физика, термодинамика и электродинамика,
  восемь ключевых формул и четыре шага подготовки. Из карточек разделов можно
  сразу перейти к викторине по теме.
- **Викторина** — 12 вопросов по четырём темам с четырьмя вариантами ответа,
  мгновенной проверкой, разбором и личным рекордом.
- **Об авторе** — карточка автора (@Jimmy), история проекта, технологии и планы.

Вкладка открывается по хешу: `#course`, `#quiz`, `#author`.
Вкладки листаются стрелками клавиатуры, когда на них установлен фокус.

## Что умеет викторина

- четыре темы: кинематика, динамика и законы сохранения, МКТ и термодинамика, электричество;
- 12 вопросов с четырьмя вариантами ответа;
- мгновенная проверка, правильный ответ и объяснение с формулой;
- прогресс, счёт и разбор ошибок в конце;
- личный рекорд по каждой теме сохраняется в `localStorage`;
- управление с клавиатуры: `1`–`4` — ответ, `Enter` — следующий вопрос;
- адаптивная вёрстка для телефона, планшета и компьютера;
- иллюстрации — SVG-заглушки, сгенерированные скриптом.

## Структура

```
index.html              разметка вкладок и экранов викторины
assets/styles.css       оформление и адаптив
assets/app.js           вопросы, логика викторины, вкладки, рекорды
assets/images/q01–q12.svg   картинки-заглушки
scripts/make-images.mjs генератор заглушек
```

## Как изменить вопросы

Вопросы лежат в массиве `QUESTIONS` в `assets/app.js`:

```js
{
  topic: "kinematics",           // ключ темы из TOPICS
  image: "assets/images/q01.svg",
  alt: "Описание иллюстрации",
  text: "Текст вопроса",
  options: ["Вариант 1", "Вариант 2", "Вариант 3", "Вариант 4"],
  correct: 1,                    // индекс верного варианта до перемешивания
  explanation: "Разбор ответа"
}
```

При старте варианты ответа перемешиваются, поэтому позиции на экране
не совпадают с порядком в массиве.

## Как заполнить страницу автора

В `index.html` найдите вкладку `id="tab-author"`. Ник создателя указан
в трёх местах и меняется одинаково:

- бейдж `<p class="author-nick">@Jimmy</p>` под заголовком;
- строка `<li><b>Автор</b><span>@Jimmy</span></li>` в списке фактов;
- подпись «Автор и вёрстка — @Jimmy» и подвал страницы.

Там же можно заменить заголовок «Автор проекта», подпись «Ученик 10 класса»,
текст приветствия и блоки «Зачем этот сайт», «Как он сделан» и «Планы».
В разметке есть комментарий с напоминанием.

## Замена иллюстраций

Каждую заглушку можно заменить обычной картинкой: положите файл в
`assets/images/` и укажите его в поле `image` нужного вопроса. Заглушки
перегенерируются командой:

```bash
node scripts/make-images.mjs
```

Палитра заглушек задаётся объектом `C` в начале `scripts/make-images.mjs`:
тёмный фон и фиолетовый акцент, чтобы картинки совпадали с темой сайта.
